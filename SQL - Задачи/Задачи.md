## 1 Задание

### 1 Запрос:
Составьте запрос, который выведет имя вида (species.species_name) с наименьшим id (species.species_id). 

### Решение:
select species_name
from species 
Where species_id = (Select MIN(species_id)From species);


### 2 Запрос:
Составьте запрос, который выведет имя вида (species.species_name) с количеством представителей (species.species_amount) более 1800.

### Решение:
select species_name
from species 
Where species_amount > 1800;


### 3 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), начинающегося на «п» и относящегося к типу 5 (species.type_id = 5).

### Решение:
select species_name
from species 
Where species.type_id = 5
AND species_name LIKE 'п%';


### 4 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), заканчивающееся на «са», или количество представителей (species.species_amount) которого равно 5.

### Решение:
select species_name
from species 
Where species.species_amount = 5
OR species_name LIKE '%са';



## 2 Задание


### 1 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), появившегося в 2023 году (species.date_start).

### Решение:
select species_name
from species 
Where to_char(date_start,'YYYY') = '2023';


### 2 Запрос:
Составьте запрос, который выведет имя (species.species_name) отсутствующего (species_status = 'absent') вида, расположенного в месте с id, равным 3 (places.place_id = 3). 
Для написания запроса вам понадобятся две таблицы — species и species_in_places. 

### Решение:
select s.species_name 
from species AS s
Inner Join species_in_places AS sp 
On s.species_id = sp.species_id
Where s.species_status = 'absent'
AND sp.place_id = 3;


### 3 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), расположенного в доме (places.place_name = 'дом') и появившегося в мае (species.date_start), а также количество представителей вида (species.species_amount). 
Для написания запроса вам понадобятся три таблицы — species, species_in_places и places.

### Решение:
select s.species_name,
       s.species_amount
from species AS s
Inner Join species_in_places AS sp
On s.species_id = sp.species_id
Inner Join places AS p
On p.place_id = sp.place_id
Where to_char(date_start,'MM') = '05' AND p.place_name = 'дом';


### 4 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), состоящее из двух слов (содержит пробел).

### Решение:
select species_name
from species
Where species_name LIKE '% %';


## 3 Задание

### 1 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), появившегося с малышом в один день(species.date_start).

### Решение:
Select species_name
From species 
Where date_start = (Select date_start
                    From species
		    Where species_name = 'малыш')
AND species_name <> 'малыш';


### 2 Запрос:
Составьте запрос, который выведет имя вида (species.species_name), расположенного в здании с наибольшей площадью(places.place_size). 
Зданиями считаются только дом и сарай. Для написания запроса вам понадобятся три таблицы — species, species_in_places и places.

### Решение:
Select species_name
From species AS s
Join species_in_places AS sp on s.species_id = sp.species_id
Join places AS p on p.place_id = sp.place_id
Where p.place_id = (Select place_id
                  From places
                  Where place_name = 'дом' OR place_name = 'сарай'
                  Order by place_size Desc
                  Limit 1);


### 3 Запрос:
Составьте запрос/запросы, которые найдут имя вида (species.species_name), относящегося к пятому по численности виду, проживающему дома (places.place_name='дом'). 
Для написания запроса вам понадобятся три таблицы — species, species_in_places и places.

### Решение:
Select s.species_name
From species AS s
Join species_in_places AS sp ON s.species_id = sp.species_id
Join places AS p ON sp.place_id = p.place_id
Where p.place_name = 'дом'
Order BY s.species_amount DESC
LIMIT 1 OFFSET 4;


### 4 Запрос:
Составьте запрос, который выведет имя сказочного вида (species.species_name), не расположенного ни в одном месте. 
Вид считается сказочным, если его статус — fairy (species.species_status = 'fairy'). 
Для написания запроса вам понадобятся две таблицы — species и species_in_places.

### Решение:
Select species_name,
       species_status
From species AS s
Left Join species_in_places AS sp on s.species_id = sp.species_id

Where s.species_status = 'fairy';
